# 투폰문자체커 (two-phone-sms-checker)

한 폰에 도착한 문자·카카오톡 등의 알림을 다른 폰에서 받아 보는 안드로이드 앱입니다.
폰이 두 대든 세 대 이상이든, 같은 앱을 모든 폰에 깔고 폰마다 역할만 고르면 됩니다.

- **보내는 폰**: 이 폰에 알림이 뜨면 내용을 읽어 다른 폰으로 보냅니다. (여러 대 가능)
- **받는 폰**: 보내는 폰들의 알림을 알림으로 띄우고 목록으로 모아 보여 줍니다. (여러 대 가능)

## 사용 방법

1. 모든 폰에 APK를 설치합니다.
2. 첫 번째 폰에서 역할을 고르고 **새 연결 코드 만들기**를 누릅니다.
3. 나머지 폰에서 역할을 고르고 첫 번째 폰에 보이는 **16자리 코드를 입력**합니다.
4. 보내는 폰: **알림 접근 권한**을 켜고, 배터리 사용 제한을 풀고, 전달할 앱을 고릅니다.
   - "제한된 설정"이라며 켜지지 않으면: 설정 → 애플리케이션 → 투폰문자체커 → 오른쪽 위 ⋮ → **제한된 설정 허용**
5. 받는 폰: 알림 권한을 허용하고 배터리 사용 제한을 풉니다.
6. 보내는 폰에서 **테스트 알림 보내기**로 확인합니다.

## 문자 보내기 (받는 폰에서 작성 → 보내는 폰이 발신)

1. 보내는 폰에서 **받는 폰에서 문자 발신 허용**을 켜고 문자 발신 권한을 허용합니다.
2. 보내는 폰에서 **테스트 알림 보내기**를 한 번 누릅니다. (받는 폰이 그 폰을 알게 됩니다)
3. 받는 폰에서 **문자 보내기**를 눌러 번호와 내용을 적고 보냅니다. 보내는 폰이 여러 대면 어느 폰의 번호로 보낼지 고릅니다.
4. 문자는 보내는 폰의 번호로 발신되고, 결과가 받는 폰에 알림으로 돌아옵니다.

요청도 연결 코드로 암호화되므로 코드를 아는 폰만 문자를 보내게 할 수 있습니다. 요청한 지 10분이 지난 문자는 발신하지 않습니다.

## 동작 원리와 보안

- 보내는 폰은 안드로이드의 알림 접근 권한(NotificationListenerService)으로 알림 내용을 읽습니다.
- 내용은 폰 안에서 연결 코드로 만든 키로 AES-256-GCM 암호화된 뒤 중계 서버(기본값 [ntfy.sh](https://ntfy.sh))를 거쳐 전달됩니다. 중계 서버는 내용을 볼 수 없고, 연결 코드를 아는 폰만 풀 수 있습니다.
- 무료 중계 서버는 하루 전송량 제한(약 250건)이 있습니다. 필요하면 앱의 "중계 서버 변경"에 직접 운영하는 ntfy 서버 주소를 넣을 수 있습니다.
- 받는 폰은 실시간 수신을 위해 상태 알림을 항상 띄워 둡니다.

## Play 스토어 출시

출시용 파일과 Play Console 입력 내용은 [`play-store/`](play-store/README.md) 폴더에 있습니다.

## 빌드

```
./gradlew bundleRelease     # Play 스토어용 AAB (keystore.properties의 업로드 키로 서명)
./gradlew assembleSideload  # 직접 설치용 APK (저장소의 공용 키로 서명)
```

- 직접 설치용 서명 키(`signing/app.keystore`)는 어디서 빌드해도 업데이트 설치가 되도록 저장소에 들어 있습니다.
- Play 업로드 키는 저장소에 넣지 않습니다. `keystore.properties`가 없으면 `bundleRelease`도 공용 키로 서명되므로 Play에 올리면 안 됩니다.
- GitHub Actions에서 푸시할 때마다 직접 설치용 APK가 빌드됩니다.

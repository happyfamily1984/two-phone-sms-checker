## 2. 앱 액세스 권한
- **"모든 기능을 특별한 액세스 권한 없이 사용할 수 있음"** 선택 (로그인 없음)
- 단, 심사자를 위한 안내를 "안내 추가"에 적어 두는 것을 권장:
```
로그인은 없습니다. 기능 확인에는 안드로이드 기기 2대가 필요합니다.
1) 기기 A: "보내는 폰으로 설정" → "새 연결 코드 만들기" → 알림 접근 권한 허용
2) 기기 B: "받는 폰으로 설정" → 기기 A에 표시된 16자리 코드 입력
3) 기기 A에서 "테스트 알림 보내기" → 기기 B에 알림이 표시됨
4) 기기 A에서 "받는 폰에서 문자 발신 허용"을 켠 뒤, 기기 B의 "문자 보내기"에서 번호·내용을 입력하면 기기 A의 번호로 문자가 발신됨
```

- "사용자가 다른 사용자와 상호작용하거나 콘텐츠를 주고받을 수 있나요?": **예** (문자 발신 기능이 있으므로)
- 위치 공유: 아니요 / 디지털 구매: 아니요

## 6. 데이터 보안 (Data safety)

### 권장 답변 (종단 간 암호화 예외 적용)
Google 기준에서 "수집"은 데이터가 기기 밖으로 나가 개발자나 제3자가 접근할 수 있는 경우입니다.
이 앱은 내용을 사용자 기기에서 암호화해 사용자 본인의 다른 기기만 풀 수 있으므로, 종단 간 암호화 예외에 해당한다고 보고 아래처럼 답합니다.

- 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? → **아니요**
- (이 답을 고르면 이후 질문이 생략됩니다)

### 보수적 답변 (심사에서 지적받으면 이렇게 바꾸세요)
- 수집 여부: **예** / 공유: **아니요**
- 데이터 유형: **메시지 → SMS 또는 MMS**, **메시지 → 기타 인앱 메시지**
  - 수집됨, 공유 안 됨, **일시적으로 처리됨: 예**
  - 필수 여부: 필수 / 목적: **앱 기능**
- 전송 중 암호화: **예**
- 사용자가 데이터 삭제를 요청할 수 있나요: **예** (앱 안에서 기록 삭제·연결 해제, 서버에 저장 안 함)

## 7. 권한 선언 — SMS (반드시 필요)
`SEND_SMS` 권한은 "제한된 권한"이라 **권한 선언 양식**을 제출해야 합니다. AAB를 올리면 Play Console이 양식을 요청합니다.

- 앱의 핵심 기능: **기기 간 SMS·통화 동기화 또는 전송 (Cross-device synchronization or transfer of SMS and calls)**
- 설명(예시):
```
투폰문자체커는 사용자가 가진 여러 대의 안드로이드 기기 사이에서 문자 알림을 전달하는 앱입니다.
사용자가 "보내는 폰"으로 지정한 기기에서 SEND_SMS 권한을 사용해, 사용자가 자신의 다른 기기("받는 폰")에서
직접 작성하고 확인한 문자를 보내는 폰의 번호로 발신합니다. 이는 기기 간 문자 전송이라는 앱의 핵심 기능입니다.
권한은 사용자가 설정에서 "받는 폰에서 문자 발신 허용"을 켤 때 용도를 안내한 뒤에만 요청하며,
SMS 수신함을 읽지 않고(READ_SMS 미사용), 발신 요청은 사용자의 연결 코드로 종단 간 암호화됩니다.
```
- **시연 동영상** 필요: 두 기기를 화면 녹화해 유튜브(일부 공개)에 올리고 링크를 넣으세요.
  보여 줄 장면: 권한 안내 대화상자 → 권한 허용 → 받는 폰에서 문자 작성·보내기 → 보내는 폰에서 발신 → 결과 알림

> ⚠ SMS 권한 심사는 엄격합니다. 반려되면 문자 발신 기능을 뺀 Play 전용 버전을 만들 수 있으니 반려 사유를 알려 주세요.

## 8. 포그라운드 서비스 권한 선언
`FOREGROUND_SERVICE_SPECIAL_USE` 사용 이유를 선언해야 합니다.

- 유형: **특수 용도 (Special use)**
- 설명(예시):
```
받는 폰에서 사용자의 다른 기기가 보낸 알림과, 보내는 폰에서 받는 폰의 문자 발신 요청을 실시간으로 받기 위해
중계 서버와의 연결을 유지합니다. 사용자가 역할을 설정하거나 "문자 발신 허용"을 켰을 때만 시작되고,
상태 알림을 항상 표시하며, 연결 해제나 스위치를 끄면 즉시 종료됩니다.
FCM은 사용자가 직접 지정한 중계 서버를 지원하지 않고 종단 간 암호화된 개인 채널을 위해 이 방식을 사용합니다.
```
- 사용자 영향: 서비스가 중단되면 다른 기기의 알림을 받지 못함
- 시연 동영상 링크(위 SMS 동영상과 같은 것을 써도 됩니다)

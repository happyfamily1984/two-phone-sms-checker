# 스토어 등록정보

## 앱 이름 (최대 30자)
```
투폰문자체커
```

## 간단한 설명 (최대 80자)
```
다른 폰에 온 문자·카톡 알림을 한 폰에서 확인하고, 그 폰 번호로 문자까지 보내세요.
```

## 자세한 설명 (최대 4000자)
```
폰을 두 대, 세 대 쓰시나요? 업무폰을 들고 다니면서도 개인폰에 온 문자와 카톡을 놓치지 마세요.

투폰문자체커는 한 폰에 도착한 알림을 내 다른 폰으로 실시간 전달해 주는 앱입니다. 같은 앱을 모든 폰에 설치하고, 폰마다 "보내는 폰" 또는 "받는 폰" 역할만 고르면 끝입니다.

■ 주요 기능
• 실시간 알림 전달: 보내는 폰에 온 문자·카카오톡 등의 알림을 받는 폰에 바로 띄워 줍니다.
• 여러 대 연결: 보내는 폰·받는 폰 모두 여러 대를 연결할 수 있어 투폰, 쓰리폰 모두 지원합니다. 어느 폰에서 온 알림인지 폰 이름으로 구분됩니다.
• 원격 문자 발신: 받는 폰에서 번호와 내용을 적으면, 선택한 보내는 폰의 번호로 문자가 발신되고 결과가 알림으로 돌아옵니다.
• 받은 알림 모아 보기: 받은 알림을 목록으로 모아 보고, 길게 눌러 여러 개를 골라 지울 수 있습니다.
• 전달할 앱 선택: 문자 앱, 카카오톡 등 원하는 앱의 알림만 골라서 보낼 수 있습니다.

■ 안전한 종단 간 암호화
모든 내용은 폰 안에서 연결 코드로 AES-256 암호화된 뒤 전달됩니다. 개발자와 중계 서버를 포함해 연결 코드를 모르는 누구도 내용을 볼 수 없습니다. 회원가입도 필요 없습니다.

■ 사용 방법
1. 모든 폰에 앱을 설치합니다.
2. 첫 번째 폰에서 역할을 고르고 "새 연결 코드 만들기"를 누릅니다.
3. 나머지 폰에서 역할을 고르고 같은 연결 코드를 입력합니다.
4. 보내는 폰에서 알림 접근 권한을 켜면 준비 완료!

■ 권한 안내
• 알림 접근: 보내는 폰에 도착한 알림을 읽어 내 다른 폰으로 전달하기 위해 필요합니다.
• 문자 보내기(선택): 받는 폰에서 요청한 문자를 보내는 폰의 번호로 발신하기 위해 사용합니다. 켜지 않으면 사용하지 않습니다. 문자 메시지함은 읽지 않습니다.
• 알림 표시: 전달받은 알림을 보여 주기 위해 필요합니다.
• 배터리 최적화 제외: 화면이 꺼져 있어도 알림을 놓치지 않도록 연결을 유지합니다.

■ 참고
• 받는 폰은 실시간 수신을 위해 상태 알림이 항상 표시됩니다.
• 기본 중계 서버(ntfy.sh)는 무료이며 하루 전송량 제한이 있습니다. 필요하면 직접 운영하는 서버로 바꿀 수 있습니다.
• 긴 문자(한글 약 70자 초과)는 통신사에 따라 발신되지 않을 수 있습니다.
```
